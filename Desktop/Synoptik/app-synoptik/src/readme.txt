SynopTik — Documentation technique & Contexte de l'applicationCe document résume l'architecture, le fonctionnement et le déploiement actuels du projet SynopTik.1. Objectif du projetSynopTik est une application web conçue pour créer et gérer des synoptiques audiovisuels et réseau (câblage régie, plateau, vidéo, audio, transmission, etc.).Ses fonctionnalités principales :Modélisation visuelle par nœuds (appareils AV, caméras, mélangeurs, convertisseurs, switchs réseau, boîtes d'annotations).Gestion typée des connexions (SDI, HDMI, Ethernet/NDI/Dante, Fibre, XLR, USB, alimentation).Calcul dynamique des besoins électriques (puissance cumulée en watts) et extraction d'une liste de matériel (BOM / export PDF avec cartouche technique).Inspecteur latéral contextuel affichant les ports, propriétés, et la photo réelle du produit sans alourdir la base de données.2. Le Front-end (React + ReactFlow)TechnologiesVite + React@xyflow/react (ReactFlow) pour le canvas nodulaire.Lucide React pour l'iconographie.html-to-image et jspdf pour la génération de synoptiques PNG/PDF haute résolution avec cartouche technique.pocketbase (SDK JS) pour l'authentification et la synchronisation des données.Ergonomie du canvas ReactFlow (src/App.jsx)Navigation au trackpad :panOnScroll={true} + panOnScrollMode="free" : translation fluide libre à deux doigts.zoomOnPinch={true} : zoom par pincement.panOnDrag={[1]} : déplacement préservé via le clic molette à la souris.selectionOnDrag={true} : le clic gauche reste disponible pour le tracé d'un cadre de sélection multiple.Alignement & distribution : barre d'outils flottante apparaissant dès la sélection de deux nœuds ou plus.Recherche et affichage des visuels produits (src/services/productSearch.js)Aucun stockage de photo ni de binaire dans la base PocketBase (garde la base ultra-légère).À la sélection d'un équipement, le front-end interroge l'endpoint /api/product-search?q=... du serveur.Les résultats sont stockés en cache mémoire (Map) côté client pendant la session pour éviter les requêtes répétées.4. Le Serveur et PocketBase (VPS)Environnement VPSHôte : VPS Ubuntu (root@185.157.245.117).Nom de domaine : synoptik.timeobinda.fr.   Fichiers statiques du front-end : /var/www/synoptik/.Répertoire PocketBase : /var/www/pocketbase-synoptik/.Service PocketBaseService systemd : pocketbase-synoptik.service.Commande exécutée :Bash/var/www/pocketbase-synoptik/pocketbase serve --http=127.0.0.1:8091
Nginx sert d'intermédiaire HTTPS et relaie les requêtes /api/ vers 127.0.0.1:8091.Endpoint personnalisé : pb_hooks/product_search.pb.jsSitué dans /var/www/pocketbase-synoptik/pb_hooks/product_search.pb.js :Expose la route GET /api/product-search.   Effectue un relais serveur sortant pour éviter les restrictions CORS du navigateur.Ajoute des mots-clés techniques (official, filtres photo) pour éviter les homonymes non professionnels.Filtre et extrait en priorité l'URL directe d'une miniature ou de l'image commerciale hébergée sur des CDN marchands fiables (ex: idealo.com, Bing Image CDN).Exclut les plateformes généralistes non pertinentes (Pinterest, blogs, immobilier).5. Workflow de développement et déploiementDéploiement du front-endDepuis le poste local :Bashnpm run deploy
Action réalisée : vite build puis envoi des fichiers du dossier dist/ en SCP vers /var/www/synoptik/ sur le VPS.Maintenance côté VPSVérifier l'état du backend :Bashsystemctl status pocketbase-synoptik
Redémarrer PocketBase après modification d'un hook JS :Bashsystemctl restart pocketbase-synoptik
Consulter les logs de l'application :Bashjournalctl -u pocketbase-synoptik -f
